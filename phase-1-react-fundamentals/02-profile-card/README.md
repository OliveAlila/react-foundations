  # Profile Card

## Objective

Build a simple interactive profile card while learning React components, state, and event handling.

## Concepts Learned

* Components
* JSX
* useState
* Event handling
* Conditional rendering
* Component imports

## Tech Stack

* React
* TypeScript
* Vite
* CSS

## Features

* Display profile information
* Display profile image
* Display skills
* Follow/Unfollow button
* Interactive button state

## Running Locally

```bash
npm install
npm run dev
```
